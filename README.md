# Sales-Analysis-Dashboard-Power-BI-Project
📌 Project Overview

This project focuses on transforming raw sales data into meaningful business insights using Microsoft Excel and Power BI. The workflow started with data cleaning and preprocessing in Excel, followed by creating an interactive and visually appealing dashboard in Power BI.

The dashboard helps analyze sales performance, profit trends, regional performance, and category-wise insights to support data-driven decision-making.
